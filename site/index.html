Signer's Doubt

A wallet agent reads untrusted text, then proposes transactions. If that text can give it orders, whoever wrote the text is the one transacting. This page shows what Tiny Aya does when the text is poisoned.

Everything here is a mock: no chain, no keys, no funds. Addresses are fake and commands are only logged. This project defends the AI-agent form of the attack; it would not stop malware on a person's machine or a compromised signing service.
