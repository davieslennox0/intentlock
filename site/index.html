4The lock

Two checks on intent: one inside the agent, one in front of the signer

Hardening

The agent is fine-tuned on safe trajectories built from the training scenarios: finish the user's task, treat tool output as data, and say what was ignored. Training uses SafeTune's SafeGrad, which keeps a narrow fine-tune from eroding the model's general refusal behaviour. Plain fine-tuning on the same data is the comparison.

Guard

A second small adapter sees only three things: what the user asked, what the tools just returned, and the exact payload about to be signed. It answers ALLOW or BLOCK with a reason. It never sees the agent's reasoning, so a compromised agent cannot talk it round. Anything it cannot parse is a BLOCK.

6Limits

What this does not show

  • Synthetic test

    The scenarios are templated, in English, with mock tools. Results describe this test, not a motivated human attacker.

  • No adaptive attacker

    Nobody optimised attacks against the hardened agent or the guard. Someone who did would beat these templates.

  • One small model

    Tiny Aya has 3.35 billion parameters. Larger agents may behave differently.

  • Shared blind spots

    The guard is the same model family as the agent and may miss what the agent misses.
