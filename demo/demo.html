6

What this
does not show

The data did the work, not the method

Plain SFT on the same data: 0 of 179 on test, 0.9% on held-out. SafeGrad showed no advantage.

The test split is in-distribution

It shares templates with training. Held-out formats (109 attacks) are the only out-of-template check. No adaptive attacker was tested.

No mechanism found

CircuitKIT discovery ran out of memory (16 GB GPU, 31 GB CPU). Removing our fallback direction: test 19.2% → 25.0%; held-out 16.0% → 8.4% against 11.8% for a random control.

All tools are mocks

No chain. No keys.
No funds.
